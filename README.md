# 🌊 OpenOcean

Your personal AI assistant. Clean, secure, malware-free.

> Inspired by OpenClaw — rebuilt from scratch with trust-first design.

## Features
- Runs on your own machine — your data stays yours
- Connects to WhatsApp, Telegram, Discord, Slack and more
- Signed installs only — no curl-pipe-bash
- Pre-reviewed skill registry — no malware
- Hard API spend limits built in
- Works on macOS, Windows, and Linux
